## 1. Goal & success criteria

**Primary — pc_success on held-out episodes (90, 95, 99 of dr100; 17, 18, 19 of real20):**

| Outcome | pc_success | Verdict |
|---|---:|---|
| No regression | ≥ 0.15 | Pass — DR scaling does not hurt |
| Win | ≥ 0.20 | DR scaling generates real signal |
| Strong win | ≥ 0.25 | DR scaling is a credible path forward |
| Regression | < 0.15 | Sim-real gap dominates — re-evaluate DR ranges |

**Secondary — open-loop action MSE:** ≤ 5.53 (trial_7 baseline). Proxy is saturated
(`plans/2026-05-14-post-ar-next-steps.md`) so flat MSE is acceptable if pc_success holds.

**Time-to-first-trained-ckpt:** ≤ 4 h wall-clock on RTX 3080 once Phase 1 lands.
First-time end-to-end including Phase 1 dev: target ≤ 3 days.

**Out of scope:** closed-loop hardware eval (see `plans/2026-05-15-closed-loop-eval.md`),
MimicGen path, re-recording real teleop data.

## Phase 3 — Generate 80 synthetic episodes (~15 min compute)

```bash
.pixi/envs/sim/bin/python -m lerobot_isaac_synthetic.isaac_dr.replay_runner \
    --source_dataset datasets/kvgork/so101-pickplace1 \
    --n_variants 4 \
    --task "pick and place cube" \
    --env_id Isaac-SO101-PickPlace-v0 \
    --output_path datasets/_dr_replay_20x4 \
    --seed 0 \
    --camera_key d435_rgb \
    --source_tag sim_dr
```

**Per-variant seed strategy.** `replay_runner.py:269` computes
`variant_seed = effective_seed + ep_idx * 1000 + variant`. With
`seed=0, n_variants=4, max_episodes=20`:
ep 0 → seeds 0/1/2/3, ep 1 → 1000/1001/1002/1003, …, ep 19 → 19000…19003.
80 episodes, deterministic, no collisions.

**Wall-clock:** Isaac startup 120 s + per-variant ~5 s × 80 = 6.7 min compute.
Budget cap: **15 min** to absorb scene-reset stalls. > 25 min = stall;
inspect `outputs/_dr_replay_20x4/.replay_log`.

**Disk footprint:** 80 ep × ~374 frames × ~30 KB PNG ≈ 900 MB + ~5 MB parquet
+ ~1 MB meta.

**Acceptance:**


## Phase 5 — Cache warmup (~80 min one-time, CONDITIONAL on RAM)

**Cache-size estimate.** Per `CLAUDE.md §SmolVLA throughput`: 7491 frames →
6.94 GB pickle. Linear → 37 400 frames ≈ **34.6 GB pickle**.

**RAM budget:** 34.6 cache + ~8 SmolVLA + ~4 Isaac (if concurrent) ≈ 47 GB
peak. Need ≥ 64 GB total system RAM. Check with `free -g | awk '/^Mem:/ {print $7}'`
≥ 40 GB free before launching.

**Warmup invocation** (50-step dummy training pass populates + exits):

```bash
.pixi/envs/train-policy/bin/python -m lerobot_isaac_adapters.train \
    --target_arch smolvla \
    --dataset datasets/kvgork/so101-pickplace1-dr100 \
    --output_dir outputs/_dr100_cache_warmup \
    --steps 50 --batch_size 4 --cache_frames \
    -- --policy.load_vlm_weights=true --policy.device=cuda \
       --optimizer.lr=3e-5 --seed=42 --save_freq=50000
```

Expected log: `[CachedDatasetWrapper] saved cache to outputs/cache_storage/<sha>.pt (34.6 GB)`.

**Wall:** ~80 min at 4-worker parallel decode (linear from 15 min @ 7491 frames).

**Cache key:** `outputs/cache_storage/<sha1>.pt` where signature includes
`dataset_root.resolve()` (per `plans/2026-05-15-cache-pickle-to-disk-plan.md`).
Hits on Phase 6 cost ~6 s load.

**Fallback if RAM tight.** Skip Phase 5; Phase 6 wall-clock goes from
83 min → ~290 min (data-bound ~1.45 step/s vs cached ~10 step/s).

## 5. Rollback / kill criteria

**Hard rollback triggers (abandon plan):**
- **Phase 1 > 3 days dev.** Switch to **Path B — dataloader-level augmentation**
  (color jitter, random crop, geometric DR) on existing 20 real episodes.
  No Isaac Lab; ~2 h dev; no pose diversity.
- **Phase 6 pc_success @ 10 k steps < 0.05** (vs trial_7's 0.1532 @ 45 k).
  Implies dataset corruption / schema drift. Stop, re-run Phase 4 acceptance,
  inspect first parquet row of `datasets/kvgork/so101-pickplace1-dr100/`.
- **Phase 7.3 cross-eval pc_success < 0.077** (50 % of trial_7). Sim-real gap
  too large — revisit camera intrinsics + DR ranges before re-running Phase 3.

**Go/no-go gates:**

| Gate | After | Pass condition |
|---|---|---|
| G1 | Phase 1 | acceptance prints `d435_rgb` shape `[1,3,480,640]` uint8 |
| G2 | Phase 2 | `--dry_run` exit 0 with `camera_key: d435_rgb` line |
| G3 | Phase 3 | `info.json:total_episodes == 80, fps == 30` |
| G4 | Phase 4 | `info.json:total_episodes == 100`, features match real |
| G5 | Phase 5 | (optional) cache `.pt` 30–40 GB on disk |
| G6 | Phase 6 step 10 k | pc_success ≥ 0.05 (mid-train eval) |
| G7 | Phase 7 | cross-eval pc_success ≥ 0.077 |

   Widen to ±0.05 m / ±5° rotation now (more diversity, risk infeasibility) or
   keep defaults? Recommendation: keep defaults; widen on a Phase-7 regression.
